Error酱参考项目

Error酱并不是从零原创，功能主要参考以下开源项目。这里是开发过程中实际参考或依赖的项目；只借鉴交互、未复制代码的会单独注明，各项目的代码与设计仍遵循其原始许可证。近几轮重构删掉了小游戏模块与站内电子书阅读器，对应的参考条目也一并移除。

Error酱 / ErrorJ（本站自身）

本站源码仓库，记录 Error酱 的开发、部署与功能更新（具体变更明细记在仓库的 DEPLOYMENT_LOG.md 与 README 里）。站内模块：仓库（元件 / 项目 / 出入库 / BOM）、书签（目录树与卡片 / 导航视图）、笔记（Word / PDF 导入、HTML 导出、智能排版）、财务（管理员与单独授权账号可用）、工作台（资料 / 固件 / 维修 / 照片墙 / 提示词 / 账号权限 / 留言审核 / 举报处理 / 上传限制 / 日志）、地图（足迹标记、分类与 GeoJSON 导入）、留言、动态（我的动态 + 开发日志）、推荐（歌曲 / 书籍 / 网页 / 站内资源四个子页），以及注册登录与权限体系。近期改动比较大的几轮：留言与动态重构成 760px 居中列表，操作收进「三个点」菜单，筛选与发布按钮改成常驻悬浮，右下角「顶部」按钮兼作新内容导航；「下载」页改名「推荐」，删掉顶部导航栏、四个子页铺满窗口，左上角四枚悬浮图标按钮切换子页、右上角「上传 + 歌曲 / 书籍 / 网页 / 站内」常驻；歌曲页删掉搜索框与底部播放条，改成点封面播放 / 暂停，书籍页删掉检索与排序、并整体下线基于 foliate-js / Android / iOS / ChromeOS / Windows / macOS / Linux」；自定义设备名称这一项由「账号权限」里的 `site:device_name` 控制，可以开放给普通账号）；留言卡片的时间改成和动态页同一套相对时间显示（刚刚 / N 分钟前 / N 小时前 / N 天前，超过 7 天回落到完整时间戳）；留言页和动态页在宽屏下改成三栏布局 —— 中间仍是
