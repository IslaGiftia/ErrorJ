Error酱参考项目

Error酱并不是从零原创，功能主要参考以下开源项目。这里是截至 2026-10-08 的开发过程中实际参考或依赖的项目；只借鉴交互、未复制代码的会单独注明，各项目的代码与设计仍遵循其原始许可证。

Error酱 / ErrorJ（本站自身）

本站源码仓库，持续记录 Error酱 的开发、部署和功能更新。截至 2026-10-13 已包含：仓库、书签（Firefox 增量导入）、笔记（Word / PDF 导入、HTML 导出）、工作台（资料 / 固件 / 维修 / 提示词 / 账号权限 / 留言审核 / 举报处理 / 上传限制 / 日志）、地图、推荐（歌曲 / 书籍 / 网页 / 站内资源）、照片墙、留言、动态、参考项目管理、注册登录与权限体系；最近补充留言先审后发、游客内容锁定、逐项举报与举报处理、举报说明页、180 天网络与操作日志、5 秒站内通知摘要刷新、手机端动态评论输入体验修复，以及留言页体验重构（操作收进「更多」菜单、图片九宫格与灯箱查看器、常驻悬浮的筛选与发送按钮、右下角「顶部」按钮兼作新回复 / 新点赞导航）、手机端足迹分类选择面板、动态页的同构重构（栏位切换并入图标按钮、悬浮筛选与「写动态」、九宫格与灯箱、新评论导航并入「顶部」按钮）、动态页的第二轮打磨（四个悬浮按钮高度与留言页统一、筛选改成全部动态 / 分享 / 评论 / 点赞、评论区支持一层回复与按作者区分的删除 / 回复按钮、卡片「三个点」菜单移到右上角、开发日志去掉展开 / 收起全部）、留言页与动态页的内容区宽度统一（同为 760px 居中，左上 / 右下悬浮按钮同步内缩）与属地勾选文案精简，以及近期这几轮打磨：输入体验统一（回复框改成「左输入框 + 右发送」且与动态页同款同高、回复不再带属地勾选、所有输入框与图片查看器都不再显示滚动条、筛选菜单展开时整排按钮图标含「写动态」的飞机一起翻转）、动态卡片换成透明底角色立绘（不做圆形裁剪、底部渐隐）并与昵称中心对齐、分享卡改版（歌曲卡封面放大到桌面 60px / 手机 50px、只留歌名与歌手两行、播放键复用播放页的实心圆键与 play↔pause 形变，播放时封面亮起完整的主题色方框并按入口按钮同一套节奏呼吸、暂停或播完即消失且不循环；笔记卡去掉「笔记」小标签；分享生成的空正文动态也能置顶 / 编辑）、和全站标签页图标同步这套底部渐隐（渐隐烤进 PNG 透明通道，所有页面包括新标签页打开的页面都是同一张），以及这一轮的推荐页重构：下载页改名「推荐」，左上角四枚常驻纯图标按钮切换歌曲 / 书籍 / 网页 / 站内资源（四个子页一次加载好、切换只翻转显隐，正文列宽与底色对齐留言和动态页），右上角常驻「新增」按钮随子页渐入渐出（+歌曲 / +书籍 / +网页 / +站内，其中「+站内」打开分享选择弹窗）；歌曲页删掉搜索框和底部播放条、改成点封面播放 / 暂停并加主题色方框呼吸，书籍页删掉检索框、书架阅读器整体下线（`/books/read`、`/books/shared`、进度 / 书签 / 批注接口与参数、`reader.*`、foliate 依赖、`books:read` 权限点一并删除）只留浏览与下载，推荐内容页删掉原来那块 hero 统计卡、拆成网页与站内资源两个卡片视图，随后又做了第二轮打磨：删掉整条顶部导航栏、四个子页铺满窗口，四枚图标按钮与「新增」按钮改成悬浮并给图标按钮加上跟随主题的悬停提示，「新增」按钮的图标换成「上传」；四个子页右下角统一成动态页那颗「顶部」按钮，并补上「有新内容就变呼吸态（↓ 歌曲 / ↓ 书籍 / ↓ 推荐）、点击跳到新内容」的逻辑；书籍页去掉格式筛选与排序、固定按书名 A~Z；网页卡片缩小成「左缩略图 + 右标题说明」的扁卡片（一行两张），点缩略图或中间即访问，去掉「访问」按钮与「网站」角标，改用「三个点」菜单（编辑 / 置顶 / 删除）；网页编辑器去掉类型 / 分类 / 标签、保留关联书签；站长在自己上传的书籍 / 网页 / 站内资源卡片上不再看到「举报」。紧接着又放开了游客权限：留言与动态的正文、配图、属地现在对游客开放，但普通账号的昵称与点赞人名字只保留最后一个字（例如「牛大能」显示为「**能」），评论与回复区整块锁定（内容不下发，只显示「登录后可查看 N 条」的锁定块），点赞按钮、评论输入框、「回复」与「发送」都不渲染给游客，卡片上只剩「三个点」里的「举报」；非图片附件对游客只给锁定占位。推荐页里网页与工具的访问地址也对游客开放，点缩略图或卡片中间即可打开，歌曲播放流、电子书下载和站内资源跳转链接仍然要求登录。

esptool-js

Memos

Ech0

Artitalk

APlayer

Navidrome

参考其自托管音乐库的浏览与播放体验（歌单优先、封面、正在播放），GPL-3.0，仅作交互参考。

music-metadata

参考其音频标签与内嵌封面的解析范围（MP3 ID3、FLAC PICTURE、M4A covr 等），MIT 许可证；本站用 Python 标准库实现了对应的解析。

Casbin

sensitive-word
