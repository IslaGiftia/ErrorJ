网页与热搜

查询近期新闻、热梗、公开资料，以及微博、B站、抖音热搜。

支持微博、B站、抖音热搜；Search 与 Fetch 使用现有 DeepSeek Key 并按成功请求次数计费，普通聊天不会自动联网。

主动聊天

只发送到管理员 QQBot 私聊，不会主动在群里发言。

主动消息之间至少间隔 90 分钟；发送失败不会占用当天次数。

群主动

每天最多发送一次晨间简报，内容仅包含城市天气和周末/节假日提示。

群成员可 @鲸鲸 发送“设置天气城市 西安”或“清除天气城市”；系统只保存城市名，不保存精确坐标。
