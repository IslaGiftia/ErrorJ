# ErrorJ Agent

独立的 ErrorJ QQ 助手服务。当前第一版支持：

- DeepSeek 闲聊
- 元件库存查询
- 收藏网站和链接查询
- 笔记搜索与读取
- Word / PDF / TXT / Markdown 附件导入为笔记
- 笔记导出为 Markdown / TXT / 单文件 HTML 并发送到 QQ
- 已有足迹搜索
- 高德地点搜索、强匹配分类并自动新增足迹
- 解析 QQ / NapCat 位置卡片并自动新增足迹
- 群位置卡片静默缓存，随后 @机器人添加
- 自定义图片表情包分类、批量归类与按分类上传
- 官方 QQBot 主动私聊，发送失败不占用每日名额
- 搜不到地点时生成足迹页选点链接
- 管理员待审核队列查询
- 审核操作二次确认

## 安全边界

- 仅允许配置中的 QQ 管理员私聊使用；群聊默认关闭。
- 首次使用可发送 `绑定 <一次性绑定码>`，绑定成功后绑定码自动失效。
- Agent 不直接连接数据库，只能调用错误酱内部工具 API。
- 内部 API 只接受本机请求、共享令牌和显式用户身份。
- 审核操作先生成一次性确认码，两分钟内回复 `确认 123456` 才执行。
- 当前笔记数据没有逐用户所有权字段，因此第一版只供管理员或拥有 `notes:view` 的用户使用。

## 本地启动

1. 复制 `.env.example` 为 `.env` 并填写配置。
2. 启动错误酱时设置相同的 `ERRORJIANG_AGENT_TOKEN`。
3. 运行：

```powershell
python -m errorjiang_agent
```

Agent 默认监听 `127.0.0.1:8011`，OneBot 事件地址为：

```text
http://127.0.0.1:8011/onebot/event/<ONEBOT_WEBHOOK_SECRET>
```

## OneBot / NapCat

- 事件上报方式：HTTP POST
- 事件地址：上方带密钥的地址
- HTTP API 地址：`http://127.0.0.1:3000`
- 如果配置了 `ONEBOT_ACCESS_TOKEN`，Agent 调用发送接口时会附带 Bearer Token

## 常用命令

- `帮助`
- `重置对话`
- `确认 123456`

管理员可以在 `/agent` 设置页新建分类，在所选分类下批量上传自定义表情包，
也可以把已有表情整组勾选后移入其他分类。直接发送图片并配文
“保存表情 笑哭”时同样会归入“笑哭”分类。群位置卡片可在分享后 10 分钟内通过
“@折兮颜 添加刚才的标记点”使用；该流程依赖机器人能收到未 @ 的群位置事件。

主动聊天只发送到管理员 QQBot 私聊，不会主动在群里发言。它受主动聊天开关、
免打扰时段、每日上限和 90 分钟最小间隔限制；只有 QQBot 发送成功后才记录
当天名额，发送失败会在下一轮继续尝试。

高德搜索新增默认直接写入，不再要求二次确认。名称强匹配到已有的一级分类
时会自动归类，例如“春发芽葫芦头”归入“美食”；其余字段默认留空。
用户主动要求预览、修改分类或备注时，仍可使用一次性确认码流程。

普通用户只能通过已绑定的站点身份新增，并沿用站点的 `map:write` 权限。
NapCat / OneBot 的 `location` 段和 JSON 位置卡片会自动解析；如果官方 QQ Bot
没有把位置卡片作为可用字段投递给机器人，则回退到足迹页手动选点链接。

导出笔记时默认生成 `.md`，也可以要求 `.txt` 或内嵌图片的 `.html`。
直接把文档附件发给机器人即可导入笔记，成功后回复 `/notes?note=<id>` 直达链接。
