# ErrorJ Agent

独立的 ErrorJ QQ 助手服务。当前第一版支持：

- DeepSeek 闲聊
- 元件库存查询
- 收藏网站和链接查询
- 笔记搜索与读取
- Word / PDF / TXT / Markdown 附件导入为笔记
- 笔记导出为 Markdown / TXT / 单文件 HTML 并发送到 QQ
- 已有足迹搜索：支持名称、分类、城市、市区与区县地址匹配
- 高德地点搜索、强匹配分类并自动新增足迹
- 解析 QQ ARK 地图卡片、高德链接坐标和 NapCat 位置卡片并自动新增足迹
- 群位置卡片静默缓存，随后 @机器人添加
- 自定义图片表情包分类、批量归类与按分类上传
- 上传文件名关键词自动参与表情包匹配
- 人格预设、自定义表达偏好、DeepSeek 网页搜索 / 抓取与微博 / B站 / 抖音热搜
- 官方 QQBot 主动私聊，发送失败不占用每日名额
- QQBot 群晨报、成员城市天气与周末 / 节假日提醒
- 定时提醒按平台分流，QQBot 群失败自动私聊兜底
- 搜不到地点时生成足迹页选点链接
- 管理员待审核队列查询
- 审核操作二次确认

## 安全边界

- 仅允许配置中的 QQ 管理员私聊使用；群聊默认关闭。
- 首次使用可发送 `绑定 <一次性绑定码>`，绑定成功后绑定码自动失效。
- Agent 不直接连接数据库，只能调用错误酱内部工具 API。
- 内部 API 只接受本机请求、共享令牌和显式用户身份。
- 审核操作先生成一次性确认码，两分钟内回复 `确认 123456` 才执行。
- 当前笔记数据没有逐用户所有权字段，因此第一版只供管理员或拥有 `notes:view` 的用户使用。

## 本地启动

1. 复制 `.env.example` 为 `.env` 并填写配置。
2. 启动错误酱时设置相同的 `ERRORJIANG_AGENT_TOKEN`。
3. 运行：

```powershell
python -m errorjiang_agent
```

Agent 默认监听 `127.0.0.1:8011`，OneBot 事件地址为：

```text
http://127.0.0.1:8011/onebot/event/<ONEBOT_WEBHOOK_SECRET>
```

## OneBot / NapCat

- 事件上报方式：HTTP POST
- 事件地址：上方带密钥的地址
- HTTP API 地址：`http://127.0.0.1:3000`
- 如果配置了 `ONEBOT_ACCESS_TOKEN`，Agent 调用发送接口时会附带 Bearer Token

## 官方 QQBot 群全量消息

群位置卡片要在“未 @ 机器人”时被接收，需要在 QQ 开放平台为机器人开启
“接收所有消息”。开启后平台会推送 `GROUP_MESSAGE_CREATE`，本项目只缓存其中的
`ark_type=map` 位置卡片，普通群消息不会写入记忆或触发模型回复。
启动后第一次收到全量群消息会记录“已收到全量群消息事件”，结构化卡片会记录
`message_type` 和 `ark_type`，方便确认平台权限和卡片类型。

群全量消息不会触发“每句都回复”。机器人只有在消息明确包含“折兮颜 / Error酱 /
小颜”，引用并延续机器人十分钟内的回复，或上一轮对话后出现带“你”、明确追问或
连续命令时才会接话；普通群聊、感叹、链接和与机器人无关的问题保持沉默。

位置卡片优先读取 ARK 字段或高德链接中的经纬度；卡片没有坐标时，会使用
地点名称自动调用高德搜索，仍然搜不到才返回足迹页选点链接。

## 常用命令

- `帮助`
- `重置对话`
- `确认 123456`
- `设置天气城市 西安`
- `清除天气城市`

`/agent` 是纯配置控制台，不提供网页聊天入口。管理员可以在这里维护基础设置、
群友档案、长期记忆、事件时间线与表情包。表情包库支持新建分类，在所选分类下批量上传自定义表情包，
也可以把已有表情整组勾选后移入其他分类。直接发送图片并配文
“保存表情 笑哭”时同样会归入“笑哭”分类。群位置卡片可在分享后 10 分钟内通过
“@折兮颜 添加刚才的标记点”使用；该流程依赖已开启官方 QQBot 的群全量消息。

新上传的表情包会保存原始文件名，并从中提取分类和情绪关键词。例如
“晚安_猫猫睡大觉.png”可以在聊天出现“睡大觉”时优先命中。微信图片、
`screenshot`、`IMG_20261026` 等无意义名称会被忽略；升级前上传的图片
因原始文件名已丢失，只能继续使用分类和旧标签匹配。

控制台可以选择冷脸萌、温柔、理性或活力人格，并填写最多 1000 字的表达补充。
人格设置只改变表达风格，不会覆盖安全和工具规则。启用网页搜索后，折兮颜会在
需要近期新闻、热梗、公开资料或出处时调用 DeepSeek Search，必要时用 Fetch
读取单个网页正文；也可以直接查询微博、B站、抖音当前热搜榜。热搜榜只提供
标题、排名、热度和平台搜索链接，榜单内容同样作为不可信资料处理。

主动聊天受主动聊天开关、
免打扰时段、每日上限和 90 分钟最小间隔限制；只有 QQBot 发送成功后才记录
当天名额，发送失败会在下一轮继续尝试。

群主动默认关闭。启用后每天最多向配置中的 QQBot 群发送一次晨报，读取群成员
通过 `设置天气城市` 主动公布的城市名；没有成员城市时可使用管理员的默认城市，
最多汇总 3 个城市。晨报还会在周五或主要节假日开始前追加一句提醒。群消息发送
失败会转管理员私聊，私聊兜底不会写入群上下文；成员只能管理自己在当前群的天气
城市，系统不保存精确坐标。

`QQBOT_GROUP_IDS` 可用逗号分隔的群 openid 限定晨报范围；留空时只使用机器人
已经见过的 QQBot 群，不会主动扫描或加入其他群。

定时提醒会按创建时保存的平台发送：QQBot 私聊和群使用 openid 主动消息，
OneBot 保留原私聊 / 群消息逻辑。QQBot 群主动消息失败时会改发管理员私聊；
所有发送失败都会记录次数和错误，并按退避间隔重试，最多 5 次后停止。
如果提醒已经超过原定时间 2 小时仍未送达，会取消原提醒并只发送一次“提醒已
错过”的说明，避免服务重启后把几天前的旧提醒当作正常提醒补发。

高德搜索新增默认直接写入，不再要求二次确认。名称强匹配到已有的一级分类
时会自动归类，例如“春发芽葫芦头”归入“美食”；其余字段默认留空。
用户主动要求预览、修改分类或备注时，仍可使用一次性确认码流程。

普通用户只能通过已绑定的站点身份新增，并沿用站点的 `map:write` 权限。
NapCat / OneBot 的 `location` 段和 JSON 位置卡片会自动解析；如果官方 QQ Bot
的群全量消息没有开启，或位置卡片没有名称和坐标，则优先使用卡片地点名调用
高德搜索，仍然无法识别时回退到足迹页手动选点链接。

导出笔记时默认生成 `.md`，也可以要求 `.txt` 或内嵌图片的 `.html`。
直接把文档附件发给机器人即可导入笔记，成功后回复 `/notes?note=<id>` 直达链接。
