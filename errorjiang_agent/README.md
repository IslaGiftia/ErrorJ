# 鲸鲸

独立的 ErrorJ QQ 助手服务。当前第一版支持：

- OpenAI-compatible LLM Provider，默认 DeepSeek，可配置备用模型回退
- 元件库存查询
- 收藏网站和链接查询
- 笔记搜索与读取
- Word / PDF / TXT / Markdown 附件导入为笔记
- 笔记导出为 Markdown / TXT / 单文件 HTML 并发送到 QQ
- 已有足迹搜索：支持名称、分类、城市、市区与区县地址匹配
- 高德地点搜索、强匹配分类并自动新增足迹
- 解析 QQ ARK 地图卡片、高德链接坐标和 NapCat 位置卡片并自动新增足迹
- 群位置卡片识别后，管理员或已绑定成员自动添加足迹
- 长期记忆支持证据、强度、访问强化、每日衰减、软归档和恢复
- 机器人可显式召回、写入和归档个人 / 群共享长期记忆
- 全局表情包支持分类、描述、关键词、六类情绪和批量元数据维护
- 文件名优先的分层表情检索、中文片段兜底与未命中分类统计
- 表情使用次数、最近使用时间、同聊天冷却避让与待整理筛选
- 表情图库 ZIP 导入导出、SHA256 去重、路径与图片格式校验
- 机器人可调用 `sticker_list` / `sticker_update` 查看和整理图库
- 人格预设、自定义表达偏好、DeepSeek 网页搜索 / 抓取与微博 / B站 / 抖音热搜
- 官方 QQBot 主动私聊，发送失败不占用每日名额
- QQBot 群晨报、成员城市天气与周末 / 节假日提醒
- QQBot 群冷场主动聊天：自适应沉默门槛、有效接话观察、运行记录、预览试发和单群暂停
- 定时提醒按平台分流，QQBot 群失败自动私聊兜底
- 搜不到地点时生成足迹页选点链接
- 管理员待审核队列查询
- 审核操作二次确认

## 模块边界

- `adapters.py`：统一 OneBot 和官方 QQBot 的消息解析入口
- `routing.py`：群聊接话判断、群范围过滤和位置卡片放行
- `providers.py`：LLM Provider 注册表、OpenAI-compatible 实现与失败回退链
- `tools.py`：模型工具注册、权限过滤和统一执行
- `context.py`：系统提示构建与上下文消息、字符预算控制
- `persona.py`：人格预设与自定义表达偏好组合
- `research.py`：自动生成多组检索词、并行搜索、去重排序和网页抓取

默认仍使用 `DEEPSEEK_*` 配置；也可以设置 `LLM_PROVIDER=deepseek` 或
`LLM_PROVIDER=openai-compatible`，并通过 `LLM_BASE_URL`、`LLM_API_KEY`、
`LLM_MODEL` 指定主模型。设置 `LLM_FALLBACK_PROVIDER` 及对应
`LLM_FALLBACK_BASE_URL`、`LLM_FALLBACK_API_KEY`、`LLM_FALLBACK_MODEL`
后，主模型请求失败会自动尝试备用模型。

网页搜索分两档：`deepseek_web_search` 只做一次快速搜索；
`deepseek_web_research` 用于最新进展、复杂事件、原因分析和多来源核验，
会自动规划 2–4 组检索词、并行搜索、去重排序，并抓取最多 3 个网页。
两种结果都作为不可信公开资料交给模型综合，返回内容有体积上限，避免工具结果被截断。

## 安全边界

- 仅允许配置中的 QQ 管理员私聊使用；群聊默认关闭。
- 首次使用可发送 `绑定 <一次性绑定码>`，绑定成功后绑定码自动失效。
- 鲸鲸不直接连接数据库，只能调用 Error酱内部工具 API。
- 内部 API 只接受本机请求、共享令牌和显式用户身份。
- 审核操作先生成一次性确认码，两分钟内回复 `确认 123456` 才执行。
- 当前笔记数据没有逐用户所有权字段，因此第一版只供管理员或拥有 `notes:view` 的用户使用。

## 本地启动

1. 复制 `.env.example` 为 `.env` 并填写配置。
2. 启动 Error酱时设置相同的 `ERRORJIANG_AGENT_TOKEN`。
3. 运行：

```powershell
python -m errorjiang_agent
```

鲸鲸默认监听 `127.0.0.1:8011`，OneBot 事件地址为：

```text
http://127.0.0.1:8011/onebot/event/<ONEBOT_WEBHOOK_SECRET>
```

## OneBot / NapCat

- 事件上报方式：HTTP POST
- 事件地址：上方带密钥的地址
- HTTP API 地址：`http://127.0.0.1:3000`
- 如果配置了 `ONEBOT_ACCESS_TOKEN`，鲸鲸调用发送接口时会附带 Bearer Token

## 官方 QQBot 群全量消息

群位置卡片要在“未 @ 机器人”时被接收，需要在 QQ 开放平台为机器人开启
“接收所有消息”。开启后平台会推送 `GROUP_MESSAGE_CREATE`，本项目会识别
`ark_type=map`，以及高德分享的 `tuwen` 卡片；普通群消息不会写入记忆或触发
模型回复。管理员或已绑定成员分享位置卡片后会自动添加足迹，未绑定成员会收到
绑定提示，卡片仍会暂存。
启动后第一次收到全量群消息会记录“已收到全量群消息事件”，结构化卡片会记录
`message_type` 和 `ark_type`，方便确认平台权限和卡片类型。

群全量消息不会触发“每句都回复”。机器人只有在消息明确包含“鲸鲸”，引用并延续
机器人十分钟内的回复，或上一轮对话后出现带“你”、明确追问或
连续命令时才会接话；普通群聊、感叹、链接和与机器人无关的问题保持沉默。

位置卡片优先读取 ARK 字段中的经纬度；没有坐标时会展开 `surl.amap.com` 等
高德短链并解析最终 `callAPP` 参数。仍没有坐标时，会使用地点名称自动调用
高德搜索，搜不到才返回足迹页选点链接。

## 常用命令

- `帮助`
- `重置对话`
- `确认 123456`
- `设置天气城市 西安`
- `清除天气城市`

`/agent` 是纯配置控制台，不提供网页聊天入口。管理员可以在这里维护基础设置、
群友档案、长期记忆、事件时间线与表情包。表情包库支持新建分类，在所选分类下批量上传自定义表情包，
也可以把已有表情整组勾选后移动分类，或批量补充描述、关键词和情绪。直接发送图片并配文
“保存表情 笑哭”时同样会归入“笑哭”分类。群位置卡片在管理员或已绑定成员分享后
会自动添加；未绑定成员先完成账号绑定，再重新分享即可。该流程依赖已开启官方
QQBot 的群全量消息。

长期记忆会保存原话证据、来源、重要度、置信度、强度、使用次数和时间。自动上下文
只注入与当前话题有短语、关键词或中文片段命中的记忆；显式召回也会过滤完全无关的
条目。召回成功会提高强度和访问次数。每日衰减在同一数据库每天最多执行一次，
低重要度且强度耗尽的记忆会软归档；Agent 页面可切换“显示已归档”并恢复。密码、
口令、Token、API Key、密钥和验证码会拒绝写入。

机器人可以调用 `recall_long_term_memory` 按 `self / group / all` 检索记忆，
使用 `memorize_long_term_memory` 保存个人记忆或由管理员保存群共享记忆，再用
`forget_long_term_memory` 按 id 或查询词软归档。个人记忆默认只对当前账号生效，
群共享记忆只包含公开约定、共同事件和计划。

新上传的表情包会保存原始文件名，并支持独立填写描述、检索关键词和
`happy / angry / sad / shy / confused / daily` 六类情绪。例如
“晚安_猫猫睡大觉.png”可以在聊天出现“睡大觉”时优先命中。微信图片、
`screenshot`、`IMG_20261026` 等无意义名称会被忽略；升级前上传的图片
因原始文件名已丢失，可以继续使用分类和旧标签，也可以在 Agent 页面补描述。

选图顺序是原始文件名、描述、关键词、情绪、标签、分类；多个检索词都命中的
结果优先，整词没命中时才拆中文二字片段兜底。未命中时 `fold_sticker_send`
会返回当前真实分类和情绪统计，方便换词重试。用户要整理图库时，模型可以先调用
`sticker_list` 查看 id，再用 `sticker_update` 批量修改描述、关键词、情绪或分类；
删除仍然只在 Agent 页面进行。

每次实际发送表情都会记录平台、会话、搜索词、命中方式和时间。同一聊天 24 小时内
最近发过的 5 张会优先避让；只有找不到相关的新图时，才会回退到用户明确搜索的旧图。
Agent 页面支持按文件名、描述、关键词、情绪和“待整理”状态筛选，并可按最近使用、
使用次数或文件名排序。

图库可以导出为带 `manifest.json` 的 ZIP。导入时按图片真实字节识别格式、用完整
SHA256 重新生成文件标识，重复图片直接跳过；同时限制 ZIP 大小、文件数量并拒绝
绝对路径、`..` 越界路径、不支持的图片和校验失败的条目。

控制台可以选择冷脸萌、温柔、理性或活力人格，并填写最多 1000 字的表达补充。
人格设置只改变表达风格，不会覆盖安全和工具规则。启用网页搜索后，鲸鲸会在
需要近期新闻、热梗、公开资料或出处时调用 DeepSeek Search，必要时用 Fetch
读取单个网页正文；也可以直接查询微博、B站、抖音当前热搜榜。热搜榜只提供
标题、排名、热度和平台搜索链接，榜单内容同样作为不可信资料处理。

旧版人格模板中的“折兮颜 / 小颜 / 大肥鱼”等身份名会在读取设置时自动迁移为
“鲸鲸”，不会丢失其余人格规则；普通聊天、群聊和主动消息都会继续使用这份模板。

主动聊天受主动聊天开关、
免打扰时段、每日上限和 90 分钟最小间隔限制；只有 QQBot 发送成功后才记录
当天名额，发送失败会在下一轮继续尝试。

群主动默认关闭。启用后每天最多向配置中的 QQBot 群发送一次晨报，读取群成员
通过 `设置天气城市` 主动公布的城市名；没有成员城市时可使用管理员的默认城市，
最多汇总 3 个城市。晨报还会在周五或主要节假日开始前追加一句提醒。群消息发送
失败会转管理员私聊，私聊兜底不会写入群上下文；成员只能管理自己在当前群的天气
城市，系统不保存精确坐标。

群聊冷场主动聊天是独立开关，默认关闭。配置群里的真人消息会更新该群最后一次
活跃时间和共享上下文，但普通闲聊不会因此触发回复。鲸鲸会根据每个群过去 7 天
的发言间隔自动调整安静门槛，低频群每周最多尝试 3 次。群安静达到门槛后，鲸鲸
会再随机等一段时间，重新确认群里仍然没人说话，才结合最近群聊摘要、共享群记忆、
城市天气和周末 / 节假日信息生成一条短消息。模型判断没有自然话题时会输出
`SKIP` 并稍后再看。每个群默认每天最多一次。

发送后会观察 15 分钟：明确回复、引用、叫到鲸鲸或明显接续原话题才算有效反馈；
无关消息不会错误清零未回复次数。连续两次没有有效接话会暂停，等群重新活跃后
恢复。Agent 页面可以查看最近运行记录、生成预览、手动试发，以及单独暂停或恢复
某个群。发送失败和过期任务都会退避或重新随机排期，不会补发很久以前的冷场消息。

`QQBOT_GROUP_IDS` 可用逗号分隔的群 openid 限定晨报和冷场聊天范围；留空时只使用机器人
已经见过的 QQBot 群，不会主动扫描或加入其他群。

定时提醒会按创建时保存的平台发送：QQBot 私聊和群使用 openid 主动消息，
OneBot 保留原私聊 / 群消息逻辑。QQBot 群主动消息失败时会改发管理员私聊；
所有发送失败都会记录次数和错误，并按退避间隔重试，最多 5 次后停止。
如果提醒已经超过原定时间 2 小时仍未送达，会取消原提醒并只发送一次“提醒已
错过”的说明，避免服务重启后把几天前的旧提醒当作正常提醒补发。

高德搜索新增默认直接写入，不再要求二次确认。名称强匹配到已有的一级分类
时会自动归类，例如“春发芽葫芦头”归入“美食”；其余字段默认留空。
用户主动要求预览、修改分类或备注时，仍可使用一次性确认码流程。

普通用户只能通过已绑定的站点身份新增，并沿用站点的 `map:write` 权限。
NapCat / OneBot 的 `location` 段和 JSON 位置卡片会自动解析；如果官方 QQ Bot
的群全量消息没有开启，或位置卡片没有名称和坐标，则优先使用卡片地点名调用
高德搜索，仍然无法识别时回退到足迹页手动选点链接。

导出笔记时默认生成 `.md`，也可以要求 `.txt` 或内嵌图片的 `.html`。
直接把文档附件发给机器人即可导入笔记，成功后回复 `/notes?note=<id>` 直达链接。
