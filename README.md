# Error酱

Error酱 是一个自托管的个人工作与学习站点。最开始它只是想做一个电子元件库存管理系统，后来慢慢长成了一个网站：仓库、书签、笔记、工作台、AI 提示词、留言、动态、推荐和小游戏，都放在同一个站里。

- 技术栈很朴素：Python 标准库 HTTP 服务 + SQLite + 原生 HTML / CSS / JavaScript，没有前端框架，也没有构建步骤。
- 数据全部保存在自己的机器上（`data/` 目录），不依赖第三方服务。
- 手机浏览器可以直接使用，适合局域网自用，也可以放到云服务器上通过 Nginx 反代公网访问。
- 界面使用 vivo Sans SC 字体，相关说明见文末「字体」一节。

源码仓库：<https://github.com/IslaGiftia/ErrorJ>

## 功能

### 仓库（电子元件库存）

- 元件档案：型号、LCSC 编号、品牌、分类、封装、温度范围、耐压、描述、数据手册链接、最低库存提醒和图片。
- 分类树与存放位置树：默认预置电阻、电容、IC、连接器等分类，以及 `XP`、`XA`、`A~Z` 等位置，可继续扩展层级；分类和位置可以组合筛选。
- 搜索同时支持型号、LCSC 编号、位置路径、位置代码、分类名称和描述。
- 批次库存：按批次记录可用数量、已出库数量、购买日期、单价、渠道、订单号和备注；支持快速入库、快速出库。
- 出入库记录可以修改时间和备注，删除后会自动回补库存；所有删除都有二次确认。
- 项目追溯：出库时可关联项目，随时查看每个项目用了哪些元件、各用了多少。
- 待购入清单：记录想买但还没买的元件，可一键转为采购入库。
- LCSC 导入：支持立创商城导出的 `.xlsx`，自动识别字段，并可在后台按 LCSC 编号批量抓取商品图片。
- BOM 缺料对比：导入 PCB 设计软件导出的 BOM（`.csv` / `.tsv` / `.txt` / `.xlsx` / `.xls`），自动识别位号、型号、封装、数量等字段，按 LCSC 或 MPN 匹配库存，生成缺料清单并导出 CSV。
- BOM 文件夹监控：指定本机目录后，服务会定期扫描新放入的 BOM 文件并自动生成报告；同一文件内容不变时不会重复处理。
- 新建项目时可以直接选择 BOM，保存项目后自动完成对比并把报告关联到项目。
- 分类图标、图片悬停放大、搜索栏吸顶、回到顶部等细节都已处理。

### 网页收藏

- 导航模式和列表模式两种视图，支持文件夹归类和多选批量操作。
- 手动拖动排序，也可以按最近添加、最早添加、标题或文件夹排序。
- 内置失效链接检查，可以只查看失效项并批量清理。
- 支持从 Firefox 导入收藏。
- 每个收藏可以保存说明和备注，图标会缓存到本地。
- 推荐模块可以直接引用网页收藏，收藏改名后推荐卡片会自动同步。

### 学习笔记

- Markdown 源文编辑 + 实时预览，支持标题、列表、引用、代码块、表格和链接。
- 顶部固定大纲与面包屑，实时解析 H1/H2/H3，滚动时自动高亮当前小节。
- 图片可以上传、粘贴或拖拽进编辑器，上传前自动缩放到最长边 2000px。
- 笔记列表支持搜索标题、正文和标签，可按标签筛选、按更新时间或标题排序。
- 支持导入 TXT、Markdown、HTML、Word（DOC / DOCX）和 PDF，自动转换为站内 Markdown；Word 内嵌图片会提取到图库，扫描版 PDF 暂不支持 OCR。
- 单篇笔记可以导出为单文件 HTML：图片以 data URI 内嵌，正文保留 Markdown 源文，可离线打开。

### 地图

- 首页左下角有一枚圆形小地图入口（PUBG 风格），悬停显示「足迹」。有地图权限时显示最近浏览的区域：在 `/map` 拖动或缩放后回到首页，圆盘会跟着停在那个区域（比大地图缩小两级）；浅色底图用高德矢量，暗色用 Esri 深色，点开进入 `/map`。游客模式显示静态城市底图，浅色 / 暗色切换只改变颜色、不改变位置，也不会加载在线地图瓦片或显示地址信息；登录后入口会自动刷新为真实地图。新增、编辑或删除足迹后，首页圆盘会在返回页面或标签页重新可见时自动刷新；新增足迹也会进入首页左下角公开动态。所有身份模式下，地图入口都不显示网格线和「N」标记。这个圆盘（含它上方的 PING / FPS 面板）只在首页显示，其它页面都不再出现。
- 标记支持名称、别名、地址、招牌推荐、标签、备注、经纬度、打卡状态（想去 / 去过）、推荐度（1~5 星）和照片（默认每个标记最多 9 张、单张不超过 8MB，可在工作台「上传限制」调整），按分类着色并用一个字做图标。
- 分类是两级结构：一级分类（例如美食、景点、酒店）下面可以挂二级分类，管理员可以新增、改名、换色换字、删除一级或二级分类；改名时如果图标还是旧名字的首字（自动图标），会自动更新为新名字首字，手动设置的自定义图标会保留，已经标记的地点会跟着分类名字和图标一起更新。历史上留下的占位图标（名字改过、图标还停在「新」）会在服务启动时自动修复一次，导入文件里没带图标的分类直接用分类名首字。删除一级分类时它的下级分类会一并删除，原来的标记会变成未分类。分类管理弹窗里一级分类默认折叠，点每行左侧的箭头展开或收起它的下级分类；新增一级分类或下级分类后会自动滚动到新行并选中名称，可以直接改名。
- 管理员可以编辑和管理所有标记；普通账号可以新增标记，并编辑、移动、删除自己新增的标记和照片，不能改动别人的和管理员添加的内容。
- 支持关键字搜索、一级 / 二级分类筛选、标签筛选、聚合显示、定位、全览，以及高德 / 百度导航链接。
- 支持按「添加者」筛选：下拉选择某位用户后，只显示他添加的标记；游客看到的是昵称或「普通用户」，不会暴露普通账号的用户名。
- 「添加标记」弹窗里可以按关键字搜索高德 POI：选中结果后自动填入名称、地址和坐标（GCJ-02 会自动换算成 WGS-84），不用手动复制坐标；该功能需要配置 `INVENTORY_AMAP_KEY`（高德开放平台 Web 服务 Key，个人认证每月有免费额度）。
- 底图可在右上角切换：高德矢量、高德卫星、Esri 深色、Esri 卫星和 OSM 标准；高德底图会自动做 WGS84 与 GCJ-02 坐标换算，保证标记不偏移。
- 底图按主题分别记忆：浅色模式默认高德矢量、深色模式默认 Esri 深色，在每个主题下手动换过底图后，下次进入该主题仍是你的选择；重新进入站点时会按 Error酱当前的全局主题取对应底图。深色底图额外叠加地名注记，并限制到瓦片原生缩放级别，避免放大后发虚。
- 底图瓦片由访客浏览器直接向高德 / OpenStreetMap / Esri 获取，不经过 Error酱 服务器；服务器只提供页面、标记数据和照片，所以浏览地图不会增加服务器带宽压力。
- 导入仅管理员可用（普通账号看不到导入按钮）：支持 GeoJSON、KML、GPX、CSV（名称,经度,纬度）和 MapBridge 插件导出的高德收藏（`format: mapbridge`）。普通文件可以在导入时选择坐标来源：WGS-84（OSM / Google / 本站导出）、GCJ-02（高德 / 腾讯网页导出）或 BD-09（百度），系统会自动换算成 WGS-84 后再保存；MapBridge 文件的坐标本来就是 WGS-84，会自动识别处理。目标分类留空时按文件里的分类路径自动归类（管理员会创建缺失的分类），选择具体分类则全部归入该分类；同名同坐标的标记会自动跳过，可以放心重复导入。
- 导出 GeoJSON 仅管理员可用。
- 全新安装时地图是空的，不含任何内置示例标记；迁移数据可以用页面上的导出 / 导入，或用 `tools/map_transfer.py` 在两台机器之间整体迁移（带分类树、打卡状态、评分和照片）。
- 瓦片来自高德、OpenStreetMap、Esri 的在线服务，标记数据始终只保存在自己的 `data/` 里；如果地图内容是私密的，设置 `INVENTORY_MAP_PUBLIC=0` 后地图只对管理员可见。
- 普通账号新增标记时会推送一条「新的标记点」通知（不产生角标），通知里带 `/map?place=<id>` 链接，点开自动定位到该标记并弹出详情。
- 标记点卡片支持点赞和打卡（「已去过」）：登录账号和管理员都能点，重复点击即取消，取消后不会留下记录、也不会重复提醒；别人点赞或打卡自己添加的标记点时，作者会收到站内提醒（首页左下角显示「某某点赞了你的标记点 / 某某打卡了你的标记点」），首页地图入口呼吸闪烁并显示角标，打开该标记点卡片即视为已读。卡片上不展示点赞 / 打卡的用户名，只显示数量。

### 首页公开动态

- 首页左下角只在桌面端显示近 7 天的公开内容动态，严格按时间倒序排列，最上面是最新记录，不再滚动或使用上下渐隐效果。时间戳使用 `「」` 包裹，时间戳和用户名使用 Error酱主题色但不加粗，时间戳、用户名和正文之间没有额外间距。**管理员**保持默认显示 9 条、单击展开到 20 条（超出可滚动，再次单击收起），双击在当前页面隐藏、刷新首页恢复显示；**普通账号**默认只显示未读提醒（有提醒时绿色呼吸，没有就整块不显示），单击查看最近 9 条日志、双击展开到 20 条、再单击回到只看提醒，刷新首页同样回到只看提醒；**游客**不显示这块区域。
- 只展示公开内容事件：留言、游戏、歌单、书架、动态和推荐，按时间倒序取最近 7 天；仓库、书签、笔记、工作台、登录和访问记录不会进入公开动态。游客看不到左下角动态区，接口也不会返回任何动态数据。
- 管理员提醒聚合成「有 N 个待审核注册申请」「有 N 条未读留言」「有 N 条留言待审核」「有 N 个待处理举报」「有 N 个下载申请」，严格按各自最新时间参与排序，不插队；提醒正文使用与 PING 正常状态相同的绿色，并按“留言 / 工作台”按钮相同的 `3.6s` 节奏呼吸闪烁，处理完成后自动消失。首页、工作台、留言页和动态页每 5 秒刷新一次通知摘要，新举报、新留言、新回复和下载申请无需手动刷新页面即可更新角标、闪烁和列表。
- 普通账号也会收到自己的互动提醒：管理员发新动态、别人点赞或回复了自己的留言、别人回复了自己的动态评论时，「动态」或「留言」入口会呼吸并显示角标，左下角默认只留一条对应的提醒；未读时该条提醒绿色呼吸，进过对应页面（离开时提交）就算已读，默认视图里这条提醒消失，记录仍保留在展开的日志里。管理员上传歌曲、上架书籍或新增推荐时，「歌单」「书架」「推荐」入口也会显示同样的呼吸和角标，新内容卡片会呼吸提示，鼠标移入或点击后清除。管理员自己不会收到这类提醒，只在展开的日志里保留「更新了一条动态」「更新了一条推荐」这类记录，不会和绿色提醒同时出现在默认视图。留言、动态、歌单、书架、推荐统一按这套「新增类事件进提醒、更新类事件只进日志」的规则处理；足迹新增不产生首页提醒。

### 工作台

- 工作台严格仅管理员和站长可访问；普通账户即使旧数据里留有工作台权限也会被服务端拒绝，`data/workbench/` 文件也不再直接通过 `/site-files/` 开放。
- 概览、资料、固件、维修台账、提示词、账号权限、留言审核、举报处理、下载申请、上传限制、日志十一个视图；原来的 AI 提示词模块已经并进这里，成为工作台的一个标签页。留言审核同时展示正文和附件，举报处理保留内容快照和处理记录。
- 电子书、本地上传歌曲和学习笔记的分享按钮提供三个选项：分享到动态、分享到推荐页、生成外部下载链接；资料和固件保持原来的限时公开分享链接。分享到动态会新发一条带分享卡片的新动态（一条动态一张卡片），分享到推荐会进入推荐的「站内资源」分类。外部链接默认 24 小时，也支持 1 小时、6 小时、3 天、7 天和自定义时间。
- 日志视图含「内容事件 / 访问记录 / 管理审计 / 推送记录」四个标签，**仅管理员（含站长）可访问**：普通账号和游客看不到入口，直接请求日志接口也会返回 403。顶部显示今日 PV、UV、新留言和登录失败次数，访问记录提供近 7 天 PV/UV 趋势图。内容事件覆盖留言、动态、地图标记、注册、登录、资料下载、提示词修改、仓库出入库、审核和举报处理，支持按动作、账号、IP、日期、关键词筛选；访问记录支持按路径、IP、访客类型、日期筛选，显示完整 IP、源端口、目标主机和端口、省属地、来源页和设备；管理审计支持按动作、关键词、日期筛选。内容事件、访问记录和管理审计都支持分页，内容事件和访问记录可导出 CSV。网络与操作明细默认保留 180 天自动清理。
- 「账号权限」含待审核、全部账号、敏感词库、全部权限、通知设置、审计日志六个标签页。「全部权限」按游客 / 普通账户 / 管理员三个角色分配默认权限：游客只控制公开页面开关（地图始终关闭），普通账户只列写 / 管理类权限，管理员固定全部权限不可收回；「全部账号」里还能对单个账号设置“继承角色 / 允许 / 禁止”三态覆盖。
- 上传项目源码包、固件、文档和图片，记录版本、目标芯片、目标开发板、在线烧录链接和项目关联。
- 资料和固件卡片会直接显示填写的备注（最多两行，超出省略，鼠标悬浮可看全文），维修台账卡片同样显示故障现象和备注，保存后不用再点开编辑弹窗就能看到。
- 「上传限制」按类别统一调整留言附件、动态图片、歌曲、电子书、照片墙、推荐封面、足迹照片、笔记图片、笔记导入文档、工作台文件和仓库元件图片的数量与大小上限，支持逐项恢复默认；单文件上限 1KB–60MB、数量 1–100，超出范围保存时直接报错，修改会写入内容事件和管理审计。
- 维修台账记录设备、故障现象、诊断过程和处理结果，支持搜索。
- 文件统一保存在 `data/workbench/`。

### AI 提示词（工作台内）

- 工作台的「提示词」标签，管理员可见，支持搜索、分类筛选、展开、复制、新增、编辑、删除和置顶。
- 卡片采用扁宽等高布局，长内容在独立弹窗中预览，不会撑开列表。
- 初始提示词来自 `config/prompts-seed.json`，首次初始化数据库时导入。

### 歌单（听 Error酱的歌单）

- 首页模块入口，页面 `/music`。游客只能查看歌名、歌手、专辑和时长，播放器隐藏且播放流接口要求登录；登录账号可以播放，上传与编辑仅管理员。
- 页面分三段：顶栏是搜索框和上传入口，中间是可滚动的歌单，底部是播放条（进度、当前曲目、按钮组、音量）。搜索按歌名 / 歌手 / 专辑实时过滤并显示命中数量，播放中的那一首会显示跳动音柱。
- 播放条左侧的专辑封面在 46px 方框里完整铺满；没有封面时才显示居中的音符占位（占位图标用容器 class 控制显隐，不会被 lucide 重建节点影响，也不会挤占封面）。
- 音量按钮默认只显示图标，鼠标移上去才展开滑杆；在按钮上滚动滚轮就能直接调节音量（每次 5%，按住 Shift 为 10%），点击图标静音 / 取消静音，触屏设备改为点按展开。
- 管理员可以上传歌曲源文件，支持 mp3、wav、flac、m4a、aac、ogg、opus，默认单个文件最大 60MB（可在工作台「上传限制」调整）；上传后自动读取文件内的歌名、歌手、专辑，并提取内嵌封面（MP3 的 ID3 APIC、FLAC 的 PICTURE、M4A 的 covr）。多选上传时每个文件一条进度，按钮上显示总进度，上传中可以取消，已选文件会保留。
- 歌曲可以一次多选、也可以直接把文件或文件夹拖进上传区（文件夹按 3 层深度递归找音频，超过单次数量上限的自动截取并提示）；在 Chrome / Edge 下点击选择会调用系统文件选择器并记住上次打开的目录，下次上传直接接着选。
- 文件里没有标签时退而求其次从文件名猜：`歌手 - 歌名`，以及两边都是中文的 `歌名-歌手`（例如「茶汤-郁可唯」）；猜错可以在编辑弹窗里改。
- 播放器支持播放 / 暂停、上一首 / 下一首、进度拖动、音量与静音、随机播放、列表循环 / 单曲循环，并接入了系统媒体控制（Media Session），手机锁屏和耳机按键也能控制。
- 音频文件保存在 `data/site_music_files/`，封面保存在 `data/music_covers/`；播放通过受控流接口并支持 HTTP Range，拖动进度不会重新下载整首歌。本地上传歌曲可申请下载，外部链接保持公开访问且不进入申请流程。

### 书架（电子书阅读）

- 首页模块入口（在歌单和动态之间），页面 `/books`：所有访客都能浏览和阅读，上传、编辑、删除仅管理员。
- 支持 EPUB、MOBI、AZW3、FB2、CBZ、PDF、TXT 和 Markdown，默认单个文件最大 60MB（可在工作台「上传限制」调整）；EPUB 与 MOBI 会自动读取书名、作者、简介和内嵌封面，PDF 读 Info 里的标题 / 作者（首版没有封面，用占位），TXT / Markdown 走文件名（认得《书名》和「作者：某某」）。
- 电子书同样支持一次多选、拖拽文件和拖拽文件夹上传，并会记住上次打开的文件目录。
- 书架页是封面网格：搜索、按格式筛选、按最近添加 / 最近阅读 / 书名排序，卡片上带阅读进度；管理员可以在卡片上编辑、删除或生成限时分享链接。普通账户申请下载获批后可下载原文件，未批准时只能在线阅读。
- 书架卡片的操作按钮（编辑 / 举报 / 分享 / 下载）收在封面右下角的深色胶囊里，下载排在最右边；封面下方只保留书名、作者和文件大小，信息不再挤压。普通账号显示举报和自己的下载 / 申请按钮，管理员显示编辑与分享。
- 阅读器基于 MIT 许可的 [foliate-js](https://github.com/johnfactotum/foliate-js)（放在 `static/vendor/foliate/`，自带 zip.js 与 fflate），PDF 用 PDF.js 渲染；支持翻页 / 滚动切换、目录、全文搜索、字号 / 行距 / 字体、浅色 / 米黄 / 深色三套主题、阅读进度记忆、书签、划线批注。
- TXT / Markdown 会在浏览器里即时打包成一本 EPUB（内置 ZIP 写入，不引入额外依赖），所以和 EPUB 共用同一套阅读功能；Markdown 用 marked 转 HTML、DOMPurify 过滤。
- 阅读进度：登录账号存服务端（每个账号各自一份，站长记 0 号），游客存浏览器本地；书签和划线批注同理。
- 电子书文件保存在 `data/book_files/`，封面保存在 `data/book_covers/`，文件接口支持 HTTP Range。
- 少数内嵌浏览器不允许 blob iframe，阅读页会给出「直接打开原文件」的兜底提示；用最新版 Chrome / Firefox / Edge 可以正常在线阅读。

### 上传与进度反馈

- 全站统一的上传进度组件（`static/site/progress.js` + `static/site/progress.css`）：单按钮操作用按钮内部填充百分比，多文件用逐条进度行，服务端解析阶段用流动条纹表示还在处理。
- 覆盖音乐上传、留言附件、动态配图、笔记 Word / PDF 导入和工作台文件上传；上传过程中再点一次按钮即取消，已选文件会保留，可以直接重试。
- 全站统一的拖拽上传区（`static/site/dropzone.js` + `static/site/dropzone.css`）：音乐、书架、地图照片与导入文件、留言附件、动态配图、推荐封面和工作台资料都能直接把文件拖进来，拖入时目标区域高亮；拖进来的是文件夹就按类型递归找文件（默认 3 层、单次最多扫描 600 个），不符合类型的文件会跳过并提示，超出各模块单次数量上限的只取前几个。
- 音乐、书架和地图导入在 Chrome / Edge 下改用系统文件选择器（固定选择器 ID），下次上传会回到上次打开的目录；不支持该 API 的浏览器自动回退到原生选择框，行为不变。
- 进度用 XMLHttpRequest 的上传事件计算，请求体和原来的 JSON 接口完全一致，后端接口没有改动。
- 请求体上限 84MB（`MAX_REQUEST_BYTES`，Nginx 侧 `client_max_body_size 84m`）。上传走 JSON + base64，体积约为原文件的 1.37 倍，所以默认 60MB 的音乐、30MB 的固件都能正常送达；各类上限可以在工作台「上传限制」里调整（硬上限 60MB / 100 个）。各页面会读取当前设置并显示真实的限制和报错，超过上限的文件会在上传前直接提示。

### 个人站点

- 留言：游客只能进入页面查看“登录后查看”提示，不能获得留言正文、附件、点赞或 IP 属地数据。登录账号可以发表留言和回复，留言和回复都支持点赞；顶层留言实行先审后发，正文与附件作为同一审核单处理，原发布时间保持不变，审核通过后其他登录账号才能看到，待审和拒绝状态仅发布者与管理员可见。回复和楼中楼不单独审核，但继续经过敏感词、频率限制和异常提醒。
- 留言每日额度：每个账号每天（服务器本地日期）默认最多发布 9 条留言/回复，发布按钮下方会显示今天剩余条数，用完自动禁用按钮，次日 0 点恢复；站长可以在工作台「账号权限 → 权限设置」里给单个账号调高或调低（0-999 条，可恢复默认）；另有每 IP 每分钟 5 条的频率限制。
- 留言和动态的筛选：登录账号（含管理员）可以在列表上方按标签筛选——留言支持「全部 / 我的留言 / 我点赞过 / 我评论过」，动态支持「全部 / 我点赞过 / 我评论过」。筛选是本地即时过滤，没有额外请求；「我点赞过」包含点赞过的留言 / 动态正文以及它们下面的回复、评论，管理员身份发布的留言同样计入「我的留言」。当前筛选会写进网址（如 `/messages?filter=liked`、`/moments?filter=commented`），刷新和分享链接都能保持；筛选结果为空时会显示对应的空状态文案。
- 动态：记录说说和日志，默认最多 9 张配图、单张 5MB、合计 15MB（可在工作台「上传限制」调整，图片也可以直接粘贴截图），支持标签、置顶、编辑和删除；游客只能看到仅含时间的锁定占位卡，不能获得正文、图片、标签、分享卡片、点赞、评论或 IP 属地；登录账号可以查看，发布和编辑仅管理员。新增评论与回复：登录账号可以评论动态、回复别人的评论，评论和评论的点赞也照留言板的顺序排列（内容 → 爱心和用户名 → 回复 / 删除），被点赞的评论会在「动态」入口提醒；评论作者和管理员可以删除评论（删除主评论会一并删除它的回复），评论和回复不会公开 IP 属地。手机端评论输入框占满可用宽度，发送按钮保持紧凑，键盘弹出后输入区域会自动滚动到可见位置。
- 站内分享：动态里的分享卡片跟着原内容走，笔记、电子书和音乐卡片均只向登录账号开放；游客看不到动态正文，也不会获得卡片中的分享地址或播放地址。原内容被删除后卡片显示「内容已失效」。分享到推荐页的卡片归入新的「站内资源」分类；分享弹窗会跟随用户在首页选择的浅色 / 暗色主题。
- 互动提醒文案：直接回复留言提示「回复了你的留言」，回复某条回复提示「回复了你」，有人评论动态（包含回复动态里的评论）提示「评论了你的动态」；这些文案同时用于首页左下角提醒和 Webhook 推送（Webhook 里会带上被回复的人和内容片段）。
- 推荐：分网站与工具、电影、动漫三类展示；支持封面、评分、年份、观看状态和标签；网站类型可直接关联书签。游客只能查看标题、封面、简介和元数据，后端不返回访问或下载地址，操作按钮提示登录；登录账号可打开，管理仅管理员。
- 推荐卡片按内容分三档尺寸：网站与工具最小（封面 88px，缩略图用 contain 完整显示、不裁切），站内资源居中（封面 148px），电影和动漫保持大封面（2:3）。同一类型的卡片封面高度、正文高度完全一致，缺分类 / 标签 / 描述时不会大小不一，底部按钮始终对齐；标题、说明、标签放不下时才在右侧渐隐（短文字保持完整）；卡片按时间顺序在 3 / 2 / 1 列之间错位分布，间距统一。
- 关联书签的选择弹窗改成固定高度，输入关键词逐字筛选时弹窗尺寸和位置不再跳动。
- 参考项目：公开只读，管理员可以在页面内新增、编辑、删除和调整排序；现有静态条目会在首次启动时自动迁移进数据库。
- 下载申请：电子书和本地上传歌曲按“账号 + 文件”独立申请；管理员可批准、拒绝或撤销。批准后仅申请账号永久可下载，撤销后立即失效；外部推荐链接和外部歌曲链接不进入申请流程。
- 下载申请、批准、拒绝、撤销、分享链接生成和实际下载都会进入工作台内容日志；新下载申请有独立 Webhook 开关、工作台徽标和首页管理员聚合提醒。
- 留言和动态支持显示 IP 属地：国内公开到省级（例如「IP 属地：广东」），国外显示国家 / 地区。每次进入页面时「公开 IP 属地」都默认不勾选，不记忆上次选择，只有本次明确勾选才会公开；完整 IP 只入库用于安全审计，不会通过任何接口对外返回。属地解析优先使用 `INVENTORY_AMAP_KEY`（高德 IP 定位）和国内数据库兜底，海外 IP 再使用 ipwho.is 解析；不配置高德 Key 时国内和海外仍会尝试兜底解析。
- 全站提示、确认和输入操作统一使用 Error酱 站内对话框，不再调用浏览器原生 `alert / confirm / prompt`；游戏登录、举报提交、举报处理、删除确认和批注输入等场景保持同一套明暗主题与移动端样式。
- 留言和动态的文字、图片与附件默认只读：只有发布者本人和管理员能下载、复制或另存，其他访客只能在页面内查看（图片点开为站内查看弹窗）。前端加了防右键、防拖拽、防复制处理，属于劝阻级别，无法阻止截图或开发者工具直接抓取。
- 小屋里还留着一版照片墙 / 音乐原型（`static/hub.html`），音乐部分已经由正式的「歌单」接替。

## 账号与权限

默认不设置密码时是免登录模式，局域网内直接使用。设置 `INVENTORY_PASSWORD`（或运行 `python tools/set_password.py`）后会启用登录：

| 身份 | 可访问内容 |
| --- | --- |
| 游客 | 首页、参考项目、留言锁屏、动态时间占位、推荐元数据、歌单元数据、游戏大厅；不能查看留言或动态正文、播放歌曲、进入子游戏、阅读书籍或打开推荐链接。游戏、书籍和推荐可以提交举报 |
| 普通账号 | 默认拥有公开页面浏览、已审核留言和动态查看、歌单播放、书籍阅读、留言发言和 `map:write`；其余写 / 管理权限由「全部权限 → 普通账户」角色统一发放 |
| 管理员 | 全部模块；站长可以在工作台把「管理员」权限授予第二个账号 |

- 注册只需要填写用户名和密码；昵称默认显示用户名，登录后可在首页账号菜单里修改（2-16 位、支持中英文/数字/常见符号、全站唯一且会做敏感词检查，同一账号每 30 天可改一次）。
- 注册后进入待审核队列。站长/管理员在工作台「账号权限」页里同意、拒绝、停用、重置密码或删除账号。「全部权限」里按游客 / 普通账户 / 管理员三个角色维护默认权限，管理员固定全部权限、不可收回；「全部账户」里还能对单个账号设置“继承角色 / 允许 / 禁止”三态覆盖，有效权限 = 角色默认 + 单独允许 − 单独禁止。所有操作都会写入审计日志。
- 权限点覆盖仓库、书签、笔记、工作台（含提示词）、地图（新增/改全部/管分类/导出）、站点内容（歌单、书籍、链接、照片）以及「管理员」；普通账户角色默认 `map:write`，角色页只分配写 / 管理类权限，查看类权限仍在「全部账户」里按账号单独授予；留言审核、动态、推荐和地图导入不开放授权，仅管理员可用。
- 游客公开范围由「账号权限 → 全部权限 → 游客」控制：默认能进入留言、动态、推荐、歌单、游戏大厅和参考项目页面，但留言和动态只显示锁定状态或时间，推荐和歌单只返回元数据，子游戏、阅读器、播放流、推荐链接和留言附件均要求登录。地图对游客完全关闭（圆盘入口、静态底图预览和 PING / FPS 仍会显示，点击圆盘提示先注册；直接访问 `/map` 或地图接口会被拦截）。
- 敏感词库在工作台里维护，内置政治、暴力、辱骂、色情、广告几类基础词，可自行增删；匹配会忽略大小写、全角半角和空格/符号干扰，昵称命中会拒绝修改，留言昵称或正文命中直接拒发，管理端有测试框。
- 有待审核注册时，首页工作台入口会显示紫色呼吸高亮和数量角标，审核完自动消失（不需要邮件系统）。
- 工作台「账号权限 → 通知设置」可以配置 Webhook 推送，把「新注册申请 / 新待审附件 / 新留言 / 新的标记点 / 安全提醒」推送到手机或群里：安全提醒包含登录失败（同一 IP 5 分钟内失败 5 次，30 分钟内不重复）和敏感词拦截（同一场景 10 分钟内不重复）。支持企业微信、钉钉、飞书群机器人、Bark（iOS）、Server酱（微信）和通用 JSON Webhook；可以发送测试通知，最近的推送成功/失败记录也会保留在页面里。没有配置时只有站内呼吸提醒，不影响使用。
- 密码只保存 PBKDF2-SHA256 哈希；会话使用 HMAC 签名 Cookie（HttpOnly + SameSite=Lax，默认 7 天，勾选“记住我”为 30 天）。同一账号最多同时保持 1 个电脑端 + 1 个手机端（平板算手机端）会话：同类型设备再次登录会让旧会话立刻下线；退出登录、重置密码、停用账号都会立即失效。升级到这套会话机制后，旧会话需要重新登录一次。
- 登录失败 5 次会锁定 5 分钟；停用账号后已有会话立即失效。
- 写接口按 IP 限速，留言限制为每 IP 每分钟 5 条；游客不能查看留言内容，也无法触发留言写入。

## 快速开始

环境要求：Windows / macOS / Linux，Python 3.10 或更高版本。

Windows：

```bat
start-inventory.bat
```

也可以使用 `run.bat`。启动脚本会在需要时自动安装 Word / PDF 文档转换依赖。

macOS / Linux：

```bash
chmod +x run.sh
./run.sh
```

或者直接运行：

```bash
python -m pip install -r requirements.txt
python app.py
```

启动后访问 <http://127.0.0.1:8000>。

### Docker（可选）

```bash
docker compose up -d --build
```

数据仍然保存在项目目录的 `data/` 文件夹中。

### 手机局域网访问

1. 手机和电脑连接同一个 WiFi。
2. 启动服务后查看启动提示，或用 `ipconfig`（Windows）/ `ifconfig`（macOS / Linux）找到电脑的局域网 IP。
3. 手机浏览器打开 `http://电脑IP:8000`。

Windows 首次访问如果被防火墙拦截，需要放行 TCP 8000：

```text
netsh advfirewall firewall add rule name="Errorjiang 8000" dir=in action=allow protocol=TCP localport=8000
```

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `INVENTORY_HOST` | `0.0.0.0` | 监听地址 |
| `INVENTORY_PORT` | `8000` | 监听端口 |
| `INVENTORY_PASSWORD` | 空 | 设置后启用登录 |
| `INVENTORY_SECRET` | 自动生成 | 会话签名密钥，保存在 `data/auth.json` |

| `INVENTORY_ACCESS_LOG` | 关闭 | 打开访问日志 |
| `INVENTORY_LOG_DAYS` | `180` | 内容事件与访问明细的保留天数，到期自动清理 |
| `INVENTORY_MAP_PUBLIC` | `1` | 设为 `0` 时地图和地图接口仅管理员可访问 |
| `INVENTORY_AMAP_KEY` | 空 | 高德开放平台「Web 服务」Key，用于「添加标记」里的 POI 搜索，以及留言 / 动态的国内 IP 属地解析；不配置时 POI 搜索会提示先配置 Key，IP 属地仍会使用国内和海外兜底解析 |

## 公网部署

推荐结构：

```text
浏览器
  -> Nginx（80 / 443）
  -> 127.0.0.1:8000
  -> systemd 服务 errorjiang
  -> <应用目录>/app.py
  -> <应用目录>/data
```

- 反向代理示例：`deploy/nginx-errorjiang.conf`
- systemd 单元：`deploy/errorjiang.service`
- 只监听回环的 Docker 方案：`docker-compose.prod.yml`

服务器上至少要做三件事：把 `INVENTORY_PASSWORD` 写进 `/etc/errorjiang.env`、让应用只监听 `127.0.0.1`、用 Nginx 转发并配置 HTTPS。完整的部署过程见 `DEPLOYMENT_LOG.md`，面向新手的服务器维护步骤见 `ERRORJIANG_MAINTENANCE.md`。

Windows 本地部署可以用 `backup.ps1` 把整个系统（代码、数据库、BOM 报告、工作台文件）打包到 `D:\InventoryBackups`，并自动清理 30 天前的旧备份：

```powershell
powershell -ExecutionPolicy Bypass -File backup.ps1
```

Linux 服务器可以用 `tools/backup_linux.sh`，配合 cron 定时执行：

```cron
0 3 * * * bash <应用目录>/tools/backup_linux.sh <备份目录>
```

恢复时把备份解压回项目目录，再启动服务即可。

## 界面约定

- 全站统一主题：默认跟随系统深浅色，首页切换后会通过 `localStorage` 同步到其他已打开的页面；登录页、注册申请页、留言、动态、推荐和歌单都跟随同一套配色（注册页不再固定浅色）。
- 首页页脚的字体说明会贴到底部并与地图圆盘底端对齐，下面保留备案号占位行；备案完成后只需替换占位文字。
- 在 2K / 125% 等桌面显示环境下，首页标题、简介、10 个模块入口和“参考项目 / Error酱源码”会作为整体垂直居中，页脚和地图等固定元素不参与内容组居中。
- 首页 PING / FPS 是浏览器端实时测值；FPS 使用 `requestAnimationFrame`，会受屏幕刷新率限制，60Hz 屏幕显示约 60F 属于正常。手机端不显示 PING / FPS，PC 端保持显示且文字不加粗。
- 标签页文字和首页入口保持一致：留言、游戏、歌单、书架、动态、推荐、仓库、书签、笔记、工作台，地图页面和首页地图圆盘悬停提示都显示「足迹」。首页六个公共功能按钮的文字做两端对齐（两个字撑满三个字的宽度），按钮宽度收到刚好包住文字。
- 首页六个公共入口是留言、游戏、歌单、书架、动态、推荐，「歌单」是普通链接：点击在当前标签页进入，把它拖到浏览器顶部标签栏（或中键 / Ctrl+点击 / 右键在新标签页打开）会新开一个标签页进入。
- 首页四个私有模块入口（仓库、书签、笔记、工作台）固定预留缩略图高度：普通账号和游客没有缩略图时也保持和管理员一样的高度，刷新首页或从动态、留言等页面返回时不会出现方框由矮变高的跳变；预留的占位不占宽度，表情和文字始终落在按钮正中间。
- 弹窗和编辑页统一采用「固定头尾」：标题行（含关闭按钮）在滚动时贴在弹窗顶部，底部操作行（删除 / 取消 / 保存）常驻贴底，只有中间的表单内容滚动。
- 实现方式参考 `static/workbench.css` 的 `.wb-modal-head` / `.wb-modal-actions`，以及 `static/map.css`、`static/music.css`、`static/prompts.css` 里对应的 sticky 规则；新增编辑弹窗时按同样方式处理（`position: sticky` + 负 margin 抵消弹窗内边距）。

## 字体

界面使用 vivo Sans SC 可变字体（vivo Sans 官方字体包，Version 1.05）。网页端使用由官方 TTF 无损转换的 WOFF2 副本，字形集合与字重轴均未改动；字体文件和《vivo Sans 字体知识产权许可协议》位于 `static/fonts/vivo-sans/`。
